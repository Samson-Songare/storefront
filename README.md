# Django Fundamentals – Models, ORM & Migrations

This repository contains my Django learning projects, focusing on **models, ORM (Object Relational Mapping), and database migrations**.  
It represents the first part of my Django journey and demonstrates my understanding of how Django interacts with databases.

## Topics Covered

- **Django Models** – creating models and defining relationships between data.
- **ORM Queries** – querying data using Django's ORM instead of raw SQL.
- **Migrations** – managing database schema changes with Django migrations.
- **Model Relationships** – One-to-One, One-to-Many, Many-to-Many.
- **Best Practices** – organizing apps, following Django conventions.
